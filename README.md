# 🕵️‍♂️ seo-plan — 海量資料收集與 SEO 策略師

> 這是米其林 AI 開發軍團中的**專屬數據與 SEO 策略師**。專門負責全網大數據採集、競品分析、SEO 黃金關鍵字矩陣佈局、Google JSON-LD 結構化標籤生成與 Open Graph (OG) 社交卡片包裝。

## 📁 倉庫結構

```
seo-plan/
├── SKILL.md       ← 主技能文件（SEO 策略與採集規範）
└── README.md      ← 本說明文件
```

## 🚀 如何使用

對 AI 說：
> `seo-plan，請幫我的 [專案名稱] 進行全網資料收集與 SEO 關鍵字佈局。`

調度官 `peo-plan` 收到後，會自動召喚 `seo-plan` 登場！
